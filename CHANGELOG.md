# Changelog

## 1.0.0 (planned)

Not released. The release checklist in [ROADMAP_1.0.md](ROADMAP_1.0.md) remains authoritative. Physical-device workflow verification, clean upgrade testing, and release packaging checks are still pending.

## 0.9.2 (development)

- Stabilized profile save/apply/stop outcomes and atomic preset/state writes.
- Improved device discovery diagnostics and documented the Steam PC support target.
- Hardened macro parsing and custom macro storage; built-in templates are protected.
- Corrected supported gamepad-button output serialization and disabled unsupported digital-to-analog bindings.
- Restricted HUD profile/preset display to the selected device and added mapping regression coverage.

This is a development summary, not a release announcement. See [docs/UPGRADING.md](docs/UPGRADING.md) for backup and recovery guidance.
