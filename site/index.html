    Dedicated Studios

    Built for Performance & Precision

    Each peripheral category gets a dedicated, native GTK4 studio crafted for rapid game tuning and zero background bloat.

    Strop Hub Central Core

    Orchestrates device discovery, USB permissions, and input-remapper daemon states with 5-second health checks and instant profile switching.

    • One-click hardware rescan & diagnostics
    • Real-time injection state indicators
    • System tray / StatusNotifier integration

    Chroma Lighting Studio 16 RGB Effects

    Full 60 FPS interactive Chroma RGB preview canvas powered by OpenRazer. Customize color stops, custom gradients, and reactive input triggers.

    • HSV color wheel with persistent swatches
    • Wave, Breathing, Spectrum, Rain, Ripple
    • Single-device or unified multi-device sync

    Mouse Studio Dynamic Plates

    Engineered for multi-plate mice like the Razer Naga Trinity. Automatically detects attached 2-button FPS, 7-button Hex, or 12-button MMO side plates.

    • Automatic side plate detection on rescan
    • DPI stage calibration (100 to 16,000+ DPI)
    • 125Hz, 500Hz, and 1000Hz polling rate controls

    Keypad & Keyboard Studio Ergonomic Matrix

    Visual 20-key matrix configurator for Tartarus Pro, Tartarus V2, and fullsize keyboards like the BlackWidow V3 with digital media rollers.

    • 8-way thumb D-pad & analog stick emulation
    • Gamepad button mapping (South, East, Bumpers)
    • Live input capture and key swap mechanics

    Macro Studio Sequence Timeline

    Visual macro sequence timeline builder with live recording, millisecond delays, turbo repeat loops, and input-remapper parser syntax validation.

    • Built-in gaming templates (Slide Attack, Dash)
    • Modifiers: wait(), key_down(), loop(xN)
    • Saved under ~/.config/strop/macros.json

    In-Game HUD Overlay Live Binds

    Frameless, semi-transparent floating heads-up display overlay showing active key mappings and gamepad badges directly over full-screen games.

    • Remembers position, opacity, & collapsed state
    • Color-coded badges for custom vs default binds
    • Standalone launcher via strop_hud.py

    Getting Started

    Quickstart & Documentation

    Everything you need to configure your Razer gaming hardware on Linux in under five minutes.

    1

    Install the Debian Package

    Download the latest release and install it via APT. System dependencies (Python 3.14, GTK4, PyGObject, python-evdev) will be resolved automatically.

    # Download and install the latest verified Debian package
sudo apt update
sudo apt install ./strop_1.2.1_all.deb
    2

    Verify Backend Services

    Ensure the input-remapper service is active and communicating with its D-Bus daemon:

    # Verify input-remapper daemon status
systemctl status input-remapper
input-remapper-control --command hello

# Optional: Verify OpenRazer daemon if using Chroma lighting
openrazer-daemon -v
    3

    Launch Strop as Desktop User

    Important: Launch Strop as your logged-in desktop user. Never launch the GUI with sudo, as remapping profiles are stored under your personal ~/.config/strop/ directory.

    # Launch Strop directly or from your desktop application launcher
strop
    1

    Confirm Device Discovery in the Hub

    When Strop opens, your connected Razer hardware (Tartarus, Naga Trinity, BlackWidow) will appear with green status badges. Click Rescan if you recently plugged in a new peripheral.

    2

    Open Studio & Remap Inputs

    Click Launch Keypad Studio or Launch Mouse Studio. Click any key on the visual matrix to set custom keystrokes, gamepad triggers, or custom macros from your library.

    3

    Save & Apply to Hardware

    Enter a profile name (e.g. warframe or cyberpunk). Click Apply Settings. Strop immediately instructs input-remapper to begin injecting keystrokes into your games without perceptible latency.

    Strop includes standalone modular CLI launchers so you can integrate overlays or profiles into game launch scripts (e.g. Steam launch options):

    strop                 # Opens the central Hub and background system tray icon
strop_hud.py          # Launches standalone In-Game HUD overlay for active device
strop_lighting.py     # Launches standalone Chroma RGB Lighting Studio
strop_macro.py        # Launches standalone Macro Studio sequence editor
strop_keypad.py       # Launches standalone Keypad Studio matrix builder
strop_mouse.py        # Launches standalone Mouse Studio with plate detection
    No device appears in Strop Hub?

    Ensure your desktop user has read access to /dev/input/event* and that python3-evdev is installed. You can verify your user group membership with groups $USER (ensure you are in the input or plugdev group). Then click Rescan in the Hub.

    Apply or Stop profile fails with a timeout?

    Verify that the input-remapper daemon is running: systemctl status input-remapper. If it is stopped, restart it with sudo systemctl restart input-remapper and confirm connectivity using input-remapper-control --command hello.

    HUD does not stay above games on GNOME Wayland?

    On Wayland, fullscreen applications with direct scanout can bypass compositor window stacking. Run games in Borderless Windowed mode, or configure GNOME Shell window rules to enforce always-on-top positioning for Strop HUD.

    Tray icon is missing from the top panel?

    Ubuntu 26.04 GNOME uses the AppIndicator and KStatusNotifierItem Support extension to host system tray icons. Verify that this extension is enabled in the GNOME Extensions application. Even without a tray host, Strop's main Hub window remains fully operational.
