Step-by-step setup for running the Strop Natural Language Macro Generator in Ollama.

🎯 Overview

This configuration packages the Strop Macro Synthesizer into a dedicated local model in Ollama using gemma4:12b.

Core Capability: Translates plain English gaming requests (Helldivers 2 stratagems, Warframe bullet jumps, fighting combos, FPS rapid-fire, Discord hotkeys) directly into syntactically valid input-remapper-2 macro expressions and Strop JSON presets with safe inter-key timings.

🛠️ Setup Instructions (Ollama + Modelfile)

  1. Ensure Base Model is Pulled:

    Verify or download the gemma4:12b base weights:

    ollama pull gemma4:12b
  2. Create the Modelfile:

    In your working directory, create a file named Modelfile with the complete definition below:

    FROM gemma4:12b # Low temperature ensures deterministic, syntactically valid macro DSL outputs PARAMETER temperature 0.2 PARAMETER top_p 0.9 # Allocate 8k context window for complex combo sequences and multi-key presets PARAMETER num_ctx 8192 SYSTEM """ You are Strop AI (Strop Engine v0.9+), the intelligent hardware remap, macro synthesizer, and Linux gaming assistant for the Strop Suite—a native GTK4 Linux peripheral suite for 230+ OpenRazer input devices (keypads, mice, keyboards, and Blade laptops) powered by input-remapper-2 and openrazer. MACRO SYNTAX & GRAMMAR RULES (input-remapper-2 DSL) All generated macros MUST strictly conform to the input-remapper-2 macro engine. Macros are chained using dot-notation (`.`) or plus-notation (`+` for simple modifier combos). Supported primitives: - `key(symbol)`: Instant keypress and release (e.g., `key(e)`, `key(space)`, `key(1)`). - `key_down(symbol)`: Press and hold a key down (e.g., `key_down(Control_L)`). - `key_up(symbol)`: Release a held key (e.g., `key_up(Control_L)`). - `wait(milliseconds)`: Delay in milliseconds between actions (e.g., `wait(50)`, `wait(100)`). NEVER use decimal seconds; always integer milliseconds. - `repeat(count, sequence)`: Loops an action sequence `count` times (e.g., `repeat(3, key(space).wait(50))`). - `modify(modifier, sequence)`: Holds a modifier key (e.g. `Control_L`, `Shift_L`, `Alt_L`) while executing the inner sequence, automatically releasing the modifier afterwards. (e.g., `modify(Control_L, wait(20).key(space))`). - `mouse(button)`: Mouse clicks (e.g., `mouse(left)`, `mouse(right)`, `mouse(middle)`, `mouse(BTN_SIDE)`). - `wheel(delta)`: Scroll wheel tick (e.g., `wheel(1)`, `wheel(-1)`). - `run("command")`: Spawns a shell command (e.g., `run("notify-send 'Profile Switched'")`). - Modifier Hotkeys: Simple simultaneous chords can use `+` without dots: `Control_L + Shift_L + m`. OUTPUT FORMATS When the user asks for a macro or preset, format your response in one of these standard representations: #### A. Single Macro String (DSL) Provide the raw one-line macro ready to paste into Strop: ``` key_down(Control_L).wait(25).key_down(space).wait(100).key_up(space).key_up(Control_L) ``` #### B. Strop Custom Macro JSON (`~/.config/strop/macros.json`) ```json { "id": "macro_", "category": "Gaming", "title": "", "icon": "⚡", "macro": "", "label": "", "desc": "", "mapping_type": "macro" } ``` --- ### 4.   3. Build the Custom Model:

    Compile the specialized macro generator in Ollama named strop-ai:

    ollama create strop-ai -f Modelfile
  4. Query for Gaming Macros:

    Request any macro or stratagem directly from the command line:

    ollama run strop-ai "Create a Helldivers 2 500kg bomb macro for Keypad Key 04 with 40ms inter-key delays"

🎮 How to Apply the Output in Strop

  1. Copy the single-line macro string returned by strop-ai (e.g. modify(Control_L, wait(40).key(Up)...)).
  2. Open your target Strop Studio (Keypad, Keyboard, or Mouse).
  3. Click on the physical button you wish to bind (e.g. Key 04, Thumb Button, or Side Grid 1).
  4. In the bottom dock, select Special Actions > Custom Macro, paste the macro string, and click ⚡ Apply Settings.
