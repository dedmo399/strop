Strop Pair Programmer • Gemma 4:12B

Step-by-step setup for running a dedicated Strop development assistant in Ollama.

🎯 Overview

This configuration packages the architecture, constraints, testing practices, and packaging rules of the Strop project into a custom local model in Ollama using gemma4:12b.

Core Enforcement: The assistant is strictly instructed to prompt before compiling or building Debian packages, maintain zero external runtime dependencies, prevent GTK3/GTK4 test collisions, and keep code comments professional and technical.

🛠️ Setup Instructions (Ollama + Modelfile)

  1. Ensure Base Model is Pulled:

    Verify or download the gemma4:12b base weights:

    ollama pull gemma4:12b
  2. Create the Modelfile:

    In your project root or working directory, create a file named Modelfile:

    FROM gemma4:12b # Configure parameters for technical programming accuracy and deterministic outputs PARAMETER temperature 0.2 PARAMETER top_p 0.9 # Set 8k context window for managing multi-file diffs and catalog references PARAMETER num_ctx 8192 SYSTEM """ [PASTE SYSTEM PROMPT FROM SECTION 3 BELOW HERE] """
  3. Build the Custom Model:

    Compile the specialized model in Ollama named strop-dev:

    ollama create strop-dev -f Modelfile
  4. Run and Interact:

    Start a pairing session in your terminal or integrate with your editor:

    ollama run strop-dev "Review strop_core/theme.py for headless display initialization safety"
